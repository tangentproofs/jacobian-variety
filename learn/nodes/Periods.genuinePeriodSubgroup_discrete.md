## Plain English

[Λ](#/node/Periods.genuinePeriodSubgroup) is a subgroup of ℂ^g generated by integrals. Nothing about the way it was defined stops it from being dense. A dense subgroup would be fatal: the quotient ℂ^g/Λ would not be Hausdorff, there would be no charts on it, and there would be no torus.

This instance records that it does not happen. The period subgroup is discrete: every period is isolated from the others (`Jacobian/Periods/GenuinePeriodLatticeDiscrete.lean` lines 41–42). The declaration itself just extracts the first half of [periodLattice_discrete_and_span](#/node/Periods.periodLattice_discrete_and_span) (Jacobian/Periods/GenuinePeriodLatticeDiscrete.lean lines 30–35). Making it an instance is what lets the rest of the project use discreteness without naming it.

## Where the work is

The real theorem is `periodLattice_discrete'` in `Jacobian/Surface/PeriodDiscrete.lean` lines 685–686, and the argument is the analytic heart of the project (outlined at Jacobian/Surface/PeriodDiscrete.lean lines 3–16).

Given a closed chain Γ, one builds a nowhere-vanishing function whose logarithmic derivative is controlled by the Hodge decomposition of a form attached to Γ. Following that function along [chart chains](#/node/Periods.IsChain) forces an exponential to equal 1, and comparing real and imaginary parts gives: the imaginary part of a certain integral is always an integer multiple of π.

That turns into a real bilinear form B on ℂ^g which takes values in πℤ on Λ and is non-degenerate. Now take the open set of points where |B(x, ·)| < π for finitely many x spanning ℂ^g. A period in that set must be killed by B entirely, hence is 0. So 0 is isolated, and in a topological group that is discreteness (Jacobian/Surface/PeriodDiscrete.lean lines 685–727).

Combined with [the span theorem](#/node/Periods.periodLattice_span), Λ is a genuine full lattice: the `IsZLattice` instance at Jacobian/Periods/GenuinePeriodLatticeDiscrete.lean lines 44–48 is what lets Mathlib hand back a ℤ-basis of Λ, which is used at Jacobian/Periods/GenuinePeriodLatticeDiscrete.lean lines 58–61 to build the compact fundamental domain. The project does not state the rank of Λ as a theorem.
